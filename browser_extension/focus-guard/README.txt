LifeCue Focus Guard prototype v0.1

1) Extract this ZIP to a permanent folder.
2) In Chrome, open chrome://extensions
3) Turn on Developer mode.
4) Click Load unpacked and select the extracted focus-guard folder containing manifest.json.
5) Pin the extension from the Extensions menu.
6) Click it, choose “1 minute (test)”, leave Instagram checked, and click Start focus.
7) Open instagram.com in a new tab: the block page should appear. After one minute, try opening it again to verify expiry.

YouTube/Apna College are allowed. This blocks websites only in this browser, not Windows apps or Android apps. It is a prototype that can be disabled or bypassed. It is not yet connected to LifeCue’s React timer; we will integrate after testing this mechanism.
